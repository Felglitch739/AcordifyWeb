# AcordifyWeb

This is the web application for Acordify, built using React, TypeScript, and Vite.

## Tech Stack
- **Framework:** React + Vite
- **Language:** TypeScript
- **Styles:** Tailwind CSS
- **Linting:** ESLint

## Development

To run the development server locally:

```bash
npm install
npm run dev
```
